# 雲の名前あて（kumo-namae）

空の絵を見て、10種類の雲（十種雲形）の名前と高さ（上層・中層・下層）を当てる、1日5問の学習ゲーム。雨をふらす雲や、積乱雲が近づくサインも身につく。

- 遊ぶ: <https://satou-aaaaa.github.io/kumo-namae/>
- 答えは気象庁（札幌管区気象台・沖縄気象台・気象庁キッズ・「急な大雨や雷・竜巻から身を守るために」）、大阪市立科学館、ウェザーニュース、Yahoo!天気の解説に基づく。
- 空の絵はこのゲームのために SVG で描いたもの。写真は使っていない。
- このゲームは防災や天気の公式の情報の代わりではありません。本当の天気・雷・大雨の情報は、気象庁の発表と市町村の情報で確かめてください。
- 記録は遊ぶ人のブラウザ（localStorage）だけに残り、外へ送らない。外から読むのは文字（Google Fonts）だけ。
- 感想は画面の「感想を送る」から（GitHub の Issue フォーム。名前・メールは要りません）。
